# Как поставить приложение на iPhone без Mac

Скомпилировать iOS-приложение можно только на macOS — это ограничение
Apple, обойти его нечем. Но Mac не обязательно покупать: сборку делает
macOS-раннер в CI, а установка на телефон происходит уже с Windows.

Общая схема одинаковая для обоих путей:

```
Windows (пишем код) → git push → macOS-раннер в облаке (собирает .ipa) → iPhone
```

---

## Путь A — бесплатно, приложение живёт 7 дней

Подходит, чтобы начать пользоваться уже сегодня и не платить.

1. **Залей проект на GitHub** (репозиторий можно сделать приватным).
   В репозитории уже лежит `.github/workflows/ios.yml` — он сам
   поставит XcodeGen, сгенерирует проект, прогонит тесты и соберёт
   неподписанный `BetTracker-unsigned.ipa`.

2. **Скачай артефакт**: вкладка Actions → последний запуск → блок
   Artifacts → `BetTracker-unsigned-ipa`. Внутри zip — файл `.ipa`.

3. **Поставь на телефон с Windows** через
   [Sideloadly](https://sideloadly.io) (или AltStore + AltServer):
   подключи iPhone кабелем, перетащи `.ipa`, введи свой Apple ID.
   Sideloadly подпишет приложение твоей бесплатной учёткой.

4. На iPhone: Настройки → Основные → VPN и управление устройством →
   доверять своему сертификату разработчика.

Ограничения бесплатной учётки Apple:

- подпись живёт **7 дней**, дальше приложение перестаёт запускаться —
  надо переустановить тем же Sideloadly (данные SwiftData при
  переустановке поверх сохраняются, но лучше не рисковать и делать это
  до истечения срока);
- максимум 3 приложения, подписанных бесплатным Apple ID, одновременно;
- пуши (Этап 4 из спеки) на бесплатной учётке не работают.

Лимиты GitHub Actions: macOS-минуты для приватных репозиториев идут с
множителем ×10 (из 2000 бесплатных минут в месяц выходит ~200 минут
macOS). Одна сборка этого проекта — несколько минут, на личный проект
хватает с запасом. Для публичного репозитория минуты бесплатны.

## Путь B — 99 $ в год, приложение живёт год, ставится по воздуху

Когда надоест переустанавливать раз в неделю.

1. Оформить [Apple Developer Program](https://developer.apple.com/programs/)
   — 99 $ в год, оформляется с iPhone или из браузера, Mac не нужен.

2. В App Store Connect создать **API-ключ** (Users and Access → Keys) —
   он позволит CI подписывать сборки без Mac и без ручной возни с
   сертификатами.

3. Собирать через [Codemagic](https://codemagic.io) (500 бесплатных
   macOS-минут в месяц) с автоматической подписью по этому ключу и
   выгрузкой в **TestFlight**.

4. На iPhone ставится приложение TestFlight — оттуда приложение
   ставится по воздуху, без кабеля и без Windows вообще. Сборка в
   TestFlight живёт 90 дней, обновляется новым пушем.

Этот путь также снимает лимит в 3 приложения и открывает пуши через
APNs для Этапа 4.

---

## Что делать прямо сейчас

Путь A ничего не стоит и ни к чему не обязывает — можно начать с него, а
на путь B перейти в любой момент, код и репозиторий те же. Первый же
запуск CI заодно проверит, что весь код Этапа 1 компилируется и тесты
проходят: на Windows этого сделать нельзя.
