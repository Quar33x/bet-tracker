# Как поставить приложение на iPhone без Mac

Скомпилировать iOS-приложение можно только на macOS — это ограничение
Apple, обойти его нечем. Но Mac не обязательно покупать: сборку делает
macOS-раннер в GitHub Actions, а установка на телефон происходит уже с
Windows, бесплатно.

```
Windows (пишем код) → git push → macOS-раннер собирает .ipa → Windows → iPhone
```

Платить Apple 99 $ в год не нужно: приложение личное, публиковать его в
App Store мы не собираемся, пуши не используются.

---

## 1. Собрать .ipa

Всё уже настроено в `.github/workflows/ios.yml`. После каждого пуша в
GitHub раннер ставит XcodeGen, генерирует Xcode-проект, прогоняет
юнит-тесты и собирает неподписанный `.ipa`.

Забрать файл: вкладка **Actions** → последний запуск → блок
**Artifacts** → `BetTracker-unsigned-ipa`. Внутри zip лежит `.ipa`.

Сборку можно запустить и руками, без пуша: Actions → iOS build → Run
workflow.

---

## 2. Поставить на iPhone

Приложение подписывается бесплатным Apple ID. У бесплатной подписи
есть срок жизни — **7 дней**, после чего приложение перестаёт
запускаться и его нужно переподписать. Есть два способа это пережить.

### Вариант с автообновлением — AltStore (рекомендую)

[AltStore Classic](https://altstore.io) + AltServer для Windows.
AltServer висит в трее и **сам переподписывает приложение по Wi-Fi**,
пока телефон и компьютер в одной сети — то есть про семь дней можно
забыть, если хотя бы раз в неделю телефон оказывается дома.

1. Поставить AltServer на Windows, установить AltStore на iPhone
   (кабелем, один раз).
2. Скинуть `.ipa` на телефон и открыть его в AltStore → приложение
   встанет.
3. В настройках AltServer включить фоновое обновление приложений.

### Вариант попроще — Sideloadly

[Sideloadly](https://sideloadly.io): подключаешь iPhone кабелем,
перетаскиваешь `.ipa`, вводишь Apple ID. Проще в установке, но
переподписывать придётся вручную раз в неделю, с кабелем.

### После установки

На iPhone: Настройки → Основные → VPN и управление устройством →
доверять сертификату разработчика.

---

## 3. Второй пользователь

Каждый ставит приложение себе сам, со своего компьютера и **под своим
Apple ID** — так проще всего, потому что бесплатная подпись привязана к
учётке, которой подписывали. `.ipa` из Actions один и тот же, качать
его может любой, у кого есть доступ к репозиторию.

Важно: на Этапе 1 приложение полностью офлайновое, данные лежат
локально на устройстве. Общей базы у двух телефонов нет — у каждого
своя. Если нужно вести ставки вдвоём в одной базе, это Этап 3 из
`SPEC.md` (свой бэкенд), там же появится и синхронизация.

---

## Ограничения бесплатной учётки

- подпись живёт 7 дней (AltStore обновляет её сам);
- одновременно не больше 3 приложений, подписанных бесплатным Apple ID;
- пуши через APNs не работают — нам они и не нужны;
- лимиты GitHub Actions: для публичного репозитория macOS-минуты
  бесплатны и не ограничены.

Если когда-нибудь захочется ставить по воздуху без компьютера и без
семидневного срока — это Apple Developer Program (99 $ в год) плюс
выгрузка в TestFlight; код и репозиторий останутся теми же.
