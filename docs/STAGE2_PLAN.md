# Этапы 2-3: данные о матчах и аналитика

План на основе разведки источников ([DATA_SOURCES.md](DATA_SOURCES.md)).
Решение по VALORANT: ждём ключ LPDB, остальное строим параллельно.

---

## 1. Архитектура

```
                    ┌─ OpenDota ────────── Dota 2: всё
  Cron 15-30 мин ───┼─ Liquipedia MW API ─ CS2: форма, H2H, агрегаты по раундам
   (Worker)         ├─ PandaScore Free ─── все три: расписание, счёт серии
                    └─ LPDB API v3 ─────── когда одобрят: карты по всем трём
                              │
                              ▼
                        D1 (SQLite)
                              │
                    ┌─────────┴──────────┐
                    ▼                    ▼
            Claude (анализ)         JSON API
            Claude (саммари)     ──▶ iOS-приложение
```

**Cloudflare Workers + D1 + Cron Triggers.** Бесплатного тира хватает с запасом,
cron встроен, секреты (ключи PandaScore и Anthropic) живут в секретах воркера и
в бинарник приложения не попадают — требование из SPEC соблюдено.

Приложение о PandaScore, Liquipedia и Claude не знает ничего: получает готовый
JSON. Учёт ставок продолжает работать офлайн, аналитика — надстройка.

## 2. Источник по дисциплине

| | Расписание | Форма и H2H | Карты и раунды | Статы игроков |
|---|---|---|---|---|
| **Dota 2** | PandaScore / OpenDota | OpenDota `/explorer` (SQL) | OpenDota ✅ | OpenDota ✅ |
| **CS2** | PandaScore Free | Liquipedia MW API | агрегаты по раундам ✅, покарточно — LPDB/GRID | ❌ до GRID |
| **VALORANT** | PandaScore Free | PandaScore (уровень серии) | ❌ до LPDB | ❌ |

Отложено до одобрения заявок: LPDB v3 (карты по всем трём, главное для VALORANT),
GRID Open Access (официальные данные CS2 + Dota 2).

## 3. Обязательства по источникам

Не опционально, зашивается в UI сразу:

- **«Source: PandaScore»** — требование ст. 6.4 их ToS, действует и на бесплатном плане.
- **Liquipedia, CC-BY-SA 3.0** — атрибуция обязательна.
- `User-Agent: BetTrackerBot/1.0 (https://github.com/Quar33x/bet-tracker)` на всех
  запросах к Liquipedia, обязательный gzip, не чаще 1 запроса в 2 секунды и
  1 запроса в 30 секунд на `action=parse`. Кэшировать агрессивно.

## 4. Данные в D1

Зеркало матчей и производные факты — то, что приложение и модель читают готовым:

- `teams` — внешние id по источникам, алиасы к `shortName` из приложения
- `matches` — расписание, статус, счёт серии, счёт по картам где есть
- `team_form` — последние N матчей команды, агрегаты W-L по матчам/картам/раундам
- `h2h` — личные встречи пары команд
- `analyses` — предматчевый анализ: текст, факторы, модель, стоимость, время
- `summaries` — саммари прошедшего матча: то же самое

Анализы и саммари **кэшируются по (match_id, версия промпта)** — повторный
запрос по тому же матчу не тратит деньги заново.

## 5. Слой LLM

**Предматчевый анализ — `claude-opus-5`**, адаптивное мышление, `effort: high`.
Вход — собранное досье: форма обеих команд, H2H, агрегаты по картам и раундам,
составы и их изменения, контекст турнира. Выход — структурированный: ключевые
факторы за и против, на что смотреть, чего в данных не хватает.

Модель обязана явно говорить, чего она не знает. Для VALORANT сейчас нет карт и
раундов — анализ должен это писать, а не делать вид, что учёл.

**Саммари матчей — Batch API**, `claude-sonnet-5`. Асинхронно и вдвое дешевле:
матч закончился, саммари появляется к моменту, когда ты откроешь приложение.

**Кеширование промптов** — стабильный префикс (инструкции + контекст турнира)
кешируется, меняется только досье конкретного матча. Проверять по
`usage.cache_read_input_tokens`, что кеш реально читается.

Оценка при 10 анализах и 30 саммари в день — около **$60-65 в месяц**.

## 6. Порядок работ

1. ✅ **Скелет воркера**: D1, миграции, cron, JSON API, авторизация по токену.
2. ✅ **Коннекторы**: OpenDota → Dota 2, PandaScore → расписание по трём
   дисциплинам, Liquipedia → CS2 с агрегатами по раундам. Все с кэшем.
3. ✅ **Анализ и саммари** на Claude: Opus 5 по кнопке, Sonnet 5 пакетом,
   кэш по отпечатку досье, дневной потолок расходов, эндпоинт `/spend`.
4. ✅ **Экраны в приложении**: вкладка «Матчи», предматчевый разбор,
   саммари, настройки подключения, атрибуция источников.
5. ⬜ **Развернуть**: аккаунт Cloudflare, ключи, `wrangler deploy` —
   см. [backend/DEPLOY.md](../backend/DEPLOY.md).
6. ⬜ **LPDB, когда одобрят**: карты и раунды по VALORANT, пересборка досье.

Пункты 1-4 сделаны и покрыты тестами (82 на бэкенде, 28 в приложении).
Дальше нужен только аккаунт Cloudflare и два ключа.
